## About

I'm the technical lead at **FlowXera**, an AI automation consultancy in Kuala Lumpur, where I run a team of five developers across five-plus client portfolios. We take a business process from discovery to production in about three weeks: process mapping and data access in week one, a working prototype in week two, then testing, user training, and handover in week three — across healthcare, finance, e-commerce, and marketing operations.

Before that I spent five years as an engineer, building Flutter and Django products at Meem Solutions, then automation pipelines and ETL systems as a specialist.

What I actually build: **LLM agents that do real work**, n8n and Python workflows that remove manual steps, and BigQuery pipelines that turn scattered APIs into dashboards people trust. I model ROI before a build starts and instrument adoption after it ships — automation that nobody uses is not automation.

📍 Kuala Lumpur, Malaysia · 🗣️ Arabic (native), English (fluent)

## 🚀 Selected Work

### 🤖 Multi-Agent Workflow System — intake to archive
End-to-end agent system that carries a client request from first inquiry through scoping, costing, planning, and archiving. Specialised agents handle structured extraction, proposal ideation, financial calculation, and project plan generation, with human review at decision points. Bilingual Arabic/English.

### 📊 KPI Agent + Conversational Analytics
Natural-language analytics over unified Google Ads and Meta Ads data. Non-technical marketers ask questions; the agent writes the BigQuery SQL and returns the answer — no analyst in the loop.
→ [Live demo](https://kpi-agent.flowxera.com/)

### 🔁 API-Driven ETL Pipelines
Consolidated Google Ads, Meta, Xero, and Shopify APIs into a single BigQuery reporting layer with scheduled ingestion and monitoring, replacing recurring manual report assembly with self-serve dashboards.

### 📬 Email-to-Task Automation
Parser that turns unstructured inbound email into structured records, then creates and routes tasks on project boards automatically. Cut request-intake handling time and manual data-entry errors.

### 📈 Automated Analytics & BI Framework
Reporting and anomaly-detection framework built on Google Sheets, Looker Studio, and Apps Script — automated client reporting and flagged outliers without a dedicated analyst.
